# AI Contribution Policy

This project **allows contributions made with the assistance of AI tools, as long as that assistance is disclosed**.

This is not an anti-AI policy. Maintainers review every contribution by hand, and knowing how a contribution was made helps them decide how closely to look at it.

## Disclose your AI usage

Every issue, pull request, and discussion that was made with AI assistance must say so. State the tools you used, for example Claude Code, Cursor, or Copilot, and how much of the work they did. Use the pull request template if the project has one.

For example:

> This pull request was mostly written by Claude Code. I reviewed and tested every change.

Or:

> I asked ChatGPT to explain the parser, but wrote the fix myself.

Plain autocompletion of a few characters and spell-checking do not need to be disclosed. If in doubt, disclose.

## Understand what you submit

- You must understand every change you submit and be able to explain how it works without the help of AI tools.
- You must run and test your changes yourself before submitting them.
- AI-assisted issues and comments must be reviewed and edited by you. Remove the noise, verbosity, and speculation AI tends to add.

## What is not accepted

- Undisclosed AI usage. Contributions suspected of it may be closed.
- Contributions from autonomous agents, bots, or automated accounts. A person must review and post every submission.
- AI-generated media, such as images, audio, and video. Only code and text may be AI-assisted.

## Summary

- AI may be used for code and text
- All AI usage must be disclosed, naming the tools and how much they did
- Contributors must understand and test everything they submit
- Autonomous agents and AI-generated media are not allowed
- Contribution guidelines must still be followed

Read more about this and other AI contribution policies on [ai-policy.dev](https://ai-policy.dev/)
